## ✨ Возможности

- **Добавление элемента** в конец очереди через `operator<<`
- **Извлечение элемента** из начала очереди через `operator>>`
- **Объединение очередей** операторами `+` и `+=`
- **Полный набор операторов сравнения**: `==`, `!=`, `<`, `<=`, `>`, `>=`
- **Ввод и вывод всей очереди** через `operator<<` / `operator>>` для потоков
- **Глубокое копирование** (конструктор копирования и оператор присваивания)
- **Автоматическое управление памятью** — деструктор очищает все узлы

## 💡 Пример использования

```cpp
#include "Queue.h"
#include <iostream>

int main() {
    Queue q;

    // Добавление элементов
    q << 1 << 2 << 3;
    std::cout << q << std::endl;   // [ 1 2 3 ]

    // Извлечение элемента
    int x;
    q >> x;
    std::cout << "Извлечено: " << x << std::endl;  // 1
    std::cout << q << std::endl;                    // [ 2 3 ]

    // Объединение очередей
    Queue a, b;
    a << 10 << 20;
    b << 30 << 40;

    Queue c = a + b;   // c = [10, 20, 30, 40], a и b не изменились
    a += b;            // a = [10, 20, 30, 40], b не изменилось

    std::cout << "c = " << c << std::endl;
    std::cout << "a = " << a << std::endl;

    // Сравнение
    if (a == c) {
        std::cout << "a и c равны" << std::endl;
    }

    return 0;
}
```

**Вывод программы:**

```
[ 1 2 3 ]
Извлечено: 1
[ 2 3 ]
c = [ 10 20 30 40 ]
a = [ 10 20 30 40 ]
a и c равны
```

## 🧩 Описание класса

### Основные методы

| Метод | Описание |
|-------|----------|
| `Queue()` | Конструктор по умолчанию — создаёт пустую очередь |
| `Queue(const Queue& other)` | Конструктор копирования — глубокое копирование |
| `~Queue()` | Деструктор — освобождает всю память |
| `operator=(const Queue&)` | Оператор присваивания |
| `empty()` | Проверка на пустоту |
| `size()` | Количество элементов |

### Перегруженные операторы

| Оператор | Описание |
|----------|----------|
| `<<` | Добавить элемент в очередь / вывести очередь в поток |
| `>>` | Извлечь элемент / прочитать очередь из потока |
| `+` | Создать новую очередь как объединение двух |
| `+=` | Добавить элементы другой очереди в текущую |
| `==`, `!=` | Сравнение на равенство |
| `<`, `<=`, `>`, `>=` | Лексикографическое сравнение |

### Внутренняя структура

Каждый узел очереди — это `Node`:

```cpp
struct Node {
    int value;      // значение
    Node* left;     // указатель (не используется в текущей реализации)
    Node* right;    // указатель на следующий узел
};
```

Класс хранит:

- `front` — указатель на первый (головной) узел
- `back` — указатель на последний узел
- `sz` — текущий размер очереди
