## ✨ Возможности

- **Добавление элемента** в конец очереди через `operator<<`
- **Извлечение элемента** из начала очереди через `operator>>`
- **Объединение очередей** операторами `+` и `+=`
- **Полный набор операторов сравнения**: `==`, `!=`, `<`, `<=`, `>`, `>=`
- **Ввод и вывод всей очереди** через `operator<<` / `operator>>` для потоков
- **Глубокое копирование** (конструктор копирования и оператор присваивания)
- **Автоматическое управление памятью** — деструктор очищает все узлы
